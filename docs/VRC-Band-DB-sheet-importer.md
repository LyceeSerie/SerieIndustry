# 外部シートから運営登録JSONを作成

`automation/discord/tools/sheet-band-importer.html` をブラウザで直接開く。ビルド・サーバー・認証不要。サイトメニューへの追加や自動登録は行わない。

1. 初期入力済みのシートURLで「シートを読み込む」を押す。
2. 形態（バンド・ユニット・個人等）、名前、解散済みの有無で絞り込む。
3. チェックボックス、または「表示中を選択」で出力対象を選ぶ。絞り込みを変更しても選択は保持する。「選択をすべて解除」で全解除する。
4. 名前を押すと内容を確認・修正できる。修正は画面内のみで元シートへ書き戻さない。
5. 「出力ファイルを作成」を押し、表示された保存リンクからJSONをダウンロードする。
6. 管理人用Discordコマンド `/band-add` へ各JSONを添付する。自動公開はしない。再投入は別登録になる。

## 項目変換

| 元の列 | 出力先・扱い |
| --- | --- |
| アーティスト名 | 活動名。空の行は除外 |
| 形態 | 活動形態１。バンド・ユニット等の正式選択肢だけを設定。個人・ソロ？・未分類は推測せず空欄。フィルターでは元の値を使う |
| 解散済み | はい／true／1等は解散/活動停止中（休止）。いいえ／false／0は活動中。空欄は状態未記載として出力しない |
| 主な活動場所 | 活動プラットフォーム。Cluster/VRChat等をカンマ区切りへ変換 |
| X、YouTube、VRCグループ、公式サイトのリンク列 | URLのドメインに応じてX・YouTube・VRC Group・その他SNSリンクへ振り分け。YouTubeの有効な動画IDはYouTube動画URLへ。チャンネル・プレイリストはSNSリンク（Youtube）へ |
| 情報源・きっかけ、備考（タグ等）、リアルライブ可否、最終確認日、追加の未知の列 | 出力しない。備考からジャンル・属性・メンバーを推測しない |

画像・ジャンル・演奏区分・活動時間帯など元データにない情報を作らない。その他リンクは最大5件で「リンクN: URL」形式。外部リンクを読み取りに行ったり、画像を取得したりしない。URLでないリンク欄は要確認として表示し、利用者が確認して除外するまで出力を停止する。別のURLを入力してから除外確認することも可能。5件を超えたその他リンクも確認対象になる。

## JSONと安全性

既存GASのインポート許可項目のみ、文字列値の配列として出力。空欄は省略する。1項目4000文字、1件12000文字、1ファイル20件かつUTF-8で64KiB以内に分割する。制御文字・不正CSV・必要な見出しの欠落／重複・空の活動名を検証する。CSV由来文字列はtextContent／入力値で描画し、HTMLとして実行しない。出力ファイルと選択内容のプレビューを画面内で生成し、外部送信しない。認証用Secretsは使わない。同名行は自動統合せず、個別に選択できる。

既存のJSONエディターはフォームに合わせた必須項目を持つため、このツールの最小情報JSONを再編集する場合は不足する必須項目の補完が必要。Discordのband-addでは最小情報JSONを受け付ける。

## 出力する活動形態の上書き

一覧の名前を押し、内容確認の「活動形態１」をバンド／ユニット／弾き語り／歌／楽器ソロから選択して出力値を変更できる。未設定へ戻すことも可能。複数行はチェックして「選択行の出力する活動形態」→「選択行へ一括適用」で変更する。上書き対象は選択した全行（フィルターで非表示の選択行も含む）。元シートの形態は保持し、フィルターは元の形態で動く。一覧の「出力する活動形態」で変更結果を確認でき、JSONには上書き後の値を出力する。元シートへの書き戻しはしない。

一覧の「出力する活動形態」列は各行のコンボボックスとし、詳細を開かずに個別変更できる。変更値は詳細・JSONプレビュー・出力ファイルへ反映する。行のチェック状態は変えず、出力対象への追加はチェックで行う。未設定に戻す操作、一括変更、元の形態でのフィルタリングも維持する。
