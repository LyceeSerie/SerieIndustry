VRC Band DB Event Calendar

VRChatのワールド内で、VRC Band DBの公開イベントを表示するカレンダーです。

配布状況を確認しています…

ALCOM / VCCにリポジトリを追加

手動追加用URL：
https://serieindustry.com/vpm/index.json

リポジトリを追加した後、Worldsプロジェクトのパッケージ管理から「VRC Band DB Event Calendar」をインストールしてください。UnityのPackages内にあるPrefabをシーンへ配置して使用します。

Unity 2022.3 / Worlds SDK 3.10.4以降に対応。Google Sheetsの読み込みには利用者側の「Allow Untrusted URLs」の許可が必要です。
