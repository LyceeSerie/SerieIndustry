## 実行方法

`SI-HP` ディレクトリで実行する。

| 操作 | コマンド |
| --- | --- |
| ローカルの変換・検索テスト | `npm test` |
| Googleテストシートと基準データの全項目照合 | `npm run test:sheet` |
| テストシート取得・テストビルド・5174番起動 | `npm run build:test` |
| 通常シート取得・通常ビルド・5173番起動 | `npm run build` |




通常・テストともリンク共有されたCSVを認証なしで取得する。Google Cloudや認証用の環境変数は不要。

- `test:sheet` はシートを更新せず、取込結果を基準データと比較する。シートを手動変更した場合は不一致として失敗するため、基準ケース変更時は `scripts/test-band-fixtures.mjs` と対応する期待値を更新する。
- サイト上で変更を確認するだけなら、シート編集後に `build:test` を実行する。フィクスチャを毎回シートへ上書きする処理は作らない。
- 取得・検証失敗時に本番データへ切り替えてテスト成功とするフォールバックは設けない。
