# YouTube紹介動画

## フォームの追加項目

- 質問名：`YouTube動画URL`（この表記で追加）
- 種類：記述式、任意回答
- 説明：紹介したいYouTube動画のURLを1件入力してください。動画・共有・Shorts・ライブURLに対応します。チャンネルURLや埋め込みコードは入力しないでください。
- 例：`https://www.youtube.com/watch?v=M7lc1UVf-VE`

既存の「SNSリンク（Youtube）」はチャンネル等のリンクとして維持し、動画には流用しない。フォームへの質問追加は利用者が行う。

## データの流れ

フォーム回答 → GASの公開項目スナップショット → Discord審査 → 公開シート → ビルド時CSV解析 → 公開JSONのyoutubeVideoId → 埋め込み表示。

GASはHTTPSのyoutube.com（www/mを含む）、youtu.be、youtube-nocookie.comを対象に、watch?v=、共有、shorts/、live/、embed/から11文字の動画IDを検証する。外部ドメイン・チャンネルURL・HTML・不正URLを拒否し、INVALID_YOUTUBE_URLを返す。動画の存在や埋め込み許可は自動検証しない。秒数指定等のパラメーターは埋め込みへ引き継がない。

未入力は表示なし。新しい動画や変更した動画は既存の承認ルールに従い、未承認のフォーム変更は公開しない。公開JSONに生の埋め込みHTMLは入れない。フロント側も11文字の動画IDだけを許可し、固定のyoutube-nocookie.comへ埋め込む。

画像の直後・活動時間帯の前に16:9で表示し、「動画」の見出しは付けない。自動再生なし、遅延読み込み、YouTubeで開くリンクを併記する。再生できない動画はリンク先で確認する。

## Discordと旧データ

審査メッセージに「紹介動画」の確認リンクを追加。通知フォーマット更新で既存メッセージも再描画する。band-editの2つ目の項目選択にYouTube動画URLを追加し、変更・空欄による削除に対応。管理人JSON追加でも同じ正式名を利用できる。

編集項目は末尾へ追加し、既存の項目番号を変えない。公開シートも登録元列の後に動画列を追加し、既存列の位置を維持する。既知の旧見出しだけ自動移行し、無関係な見出しのシートは書き換えない。旧レコードに空欄を補うだけでは版や承認状態を変えない。次の公開処理で既存承認済みレコードも一度再出力し、動画列を反映する。

## 反映と確認

1. フォームに任意の「YouTube動画URL」を追加する。
2. GAS・Worker・サイトを既存のActionsで更新する。既存コマンドを使うため、Discordコマンドの再登録や鍵の変更は不要。
3. ローカル通知プログラムを稼働させ、回答後のDiscord通知から動画を確認・承認する。
4. 公開Actions完了後、サイトの埋め込みを確認する。

テスト用fixtureはTC01が通常動画URL、TC03が共有リンク、TC16が不正URL、TC20が未入力。サンプルの固定ID注入を廃止し、実際のCSV解析を通して表示する。実運用のデプロイと実フォーム送信は別途確認する。
