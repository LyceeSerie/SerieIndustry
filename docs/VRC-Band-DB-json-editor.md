# 運営登録JSONエディター

`automation/discord/tools/band-json-editor.html` をブラウザで直接開く。ビルド・サーバー起動・認証不要。入力内容を外部へ送信しない。サイトのメニューには追加しない。

1. バンド情報を入力する。活動名のみ必須。画像はURLで入力する。
2. バンド追加・複製で最大20件まで編集する。
3. 「JSONを書き出す」で追加バンド.jsonを保存する。
4. Discordの管理人用チャンネルで `/band-add` に添付する。

既存の運営登録JSONを読み込み、再編集できる。項目名はGASの27項目と一致。選択肢にない既存値は「その他」に保持し、勝手に削除しない。表示用サイトJSONではなく、band-add用の配列を読み込む。

活動形態・演奏区分・活動状態・ロゴ配置は単一選択。活動プラットフォーム・メインジャンル・属性・募集パートは複数選択。自由入力のサブジャンル・メンバー・コメント等はテキストで入力する。音源/動画のみ・複合ジャンルのスラッシュは保持する。

最新フォームの選択肢を外部取得できなかったため、初期候補は確認済みの仕様・データを基にした候補。全項目の完全一致は未確認。「選択肢を設定」で候補JSONを編集し適用でき、設定の書き出し・読み込みも可能。選択肢設定は登録JSONに含めない。

書き出し時に活動名、項目4000文字、全項目12000文字、20件、UTF-8で64KiBを検証。YouTube動画URLの形式と画像のhttp/https URLも検証する。画像・動画の実在や権限の確認は行わない。画像を自動取得・アップロードしない。

入力の自動保存はしない。未保存の編集がある場合はページ離脱時にブラウザの確認を出す。閉じる前にJSONを書き出す。公開ページへの自動反映や既存登録の更新はしない。書き出したファイルの再追加は別登録になるため、既存登録の修正にはband-editを使用する。

バンドメンバーはメンバー追加ボタンで行を追加し、パート・名前・XのID／プロフィールURLを個別入力する。各行の削除に対応。名前のみ必須。JSONの読み込み時は既存の縦棒区切りを入力欄へ展開し、Export時に既存形式へ自動変換する。壊れた既存メンバー文字列は無視せず読み込みエラーにし、不完全な名前や区切り文字の混入も書き出し時に検証する。

複数の自由入力項目も行別入力へ統一。サブジャンル、およびメインジャンル・属性・募集パート・活動プラットフォームの「その他」は＋ボタンで入力欄を追加し、各行を削除できる。Export時に空欄・重複を除去し、カンマ区切りへ自動変換する。既存JSONの区切り値は個別入力欄に展開する。単一選択項目のその他は引き続き1件入力。メインジャンルの複合名や音源/動画のみのスラッシュは保持する。
